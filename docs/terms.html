2. Description du service

FishBook est une application mobile permettant aux pêcheurs de :

  • Identifier des espèces de poissons via l'intelligence artificielle
  • Consulter une base de données d'espèces (Fishdex)
  • Participer à une communauté de pêcheurs
  • Suivre leurs statistiques et progresser dans un système de gamification
